## curl: DevOps'un İsviçre çakısı

`curl` terminalden HTTP istekleri atar. Amaç sadece “indirmek” değil — **görmediğin şeyi görmek**: tarayıcı seni yönlendirdi, önbellekten mi verdi, hangi durum kodu geldi? curl ham gerçeği gösterir.

```bash
# Yanıt başlıklarını göster (HTML gövdesi değil)
curl -I https://example.com

# Yönlendirmeleri takip et (her adımı ayrı ayrı göster)
curl -IL https://astro.build

# Gövdeyi dosyaya kaydet + süre istatistikleri
curl -o sayfa.html -w "süre: %{time_total}s, kod: %{http_code}\n" https://example.com
```

Kritik bayraklar:

| Bayrak | Yapar |
| --- | --- |
| `-I` | HEAD isteği; yalnızca başlıklar |
| `-L` | Redirect'leri takip et |
| `-v` | TLS handshake dahil her şeyi göster |
| `-o dosya` | Çıktıyı dosyaya yaz |
| `-X POST` | Metot seç |
| `-d '{"a":1}'` | Gövde ekle (JSON) |
| `-H "Header: değer"` | Başlık ekle |
| `-s` | Sessiz mod (script'lerde) |
| `-w` | İstatistik formatı (`http_code`, `time_total`...) |

## Bir API çağrısı

```bash
curl -s -X POST https://api.example.com/siparis \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"urun":"kitap","adet":2}' \
  -w "\nHTTP: %{http_code}\n"
```

Script'lerde `http_code` almaya özel ilgi: çıkış kodu değil **durum kodu** hata ayıklamanın dilidir (bir önceki dersten hatırla: 5xx sunucu, 4xx istemci).

## “Site erişilemiyor” diagnoz akışı

Sıradaki tek bir cümleyi ezberle: **ağdan uygulamaya doğru daralt**.

```bash
# 1. Makine ayakta mı? (ağ katmanı)
ping -c 2 staging.local

# 2. Port açık mı? (transport katmanı)
nc -zv staging.local 80

# 3. HTTP ne diyor? (uygulama katmanı)
curl -I http://staging.local

# 4. Uygulama içi sağlık?
curl -s http://staging.local/health
```

Her adım bir katmanı eler. Ping başarılı + port kapalı → firewall/uygulama kapalı. Port açık + HTTP 500 → uygulama hatası → loglara (Seviye 1'in süreçler dersindeki akış).

<Callout type="info" title="Seviye 4 bağılantısı">
  Bu akışın otomatikleştirilmiş, sürekli çalışan hali **synthetic monitoring**’dir:
  `curl -s -o /dev/null -w "%{http_code}" https://site.com` her 30 saniyede bir cron/monitor
  tarafından çalıştırılır ve başarısızsa uyarı basar. Seviye 4'te bunu Prometheus ile
  kuracağız.
</Callout>

<Callout type="info" title="Gerçek dünyadan: curl her yerde — milyarlarca cihazda">

## JSON ve script dostu ipuçları

```bash
# JSON çıktısını düzgün gör
curl -s https://api.example.com/durum | python3 -m json.tool

# Yanıt süresi ölçümü — performans şikâyetlerinde ilk kanıt
curl -s -o /dev/null -w "%{time_namelookup} DNS\n%{time_connect} bağlantı\n%{time_total} toplam\n" https://example.com
```
