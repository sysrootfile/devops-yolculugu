## Özet haritası

- **Pipeline kavramları:** kalite kapıları (build → test → analiz), CI vs Delivery vs Deployment, küçük parça prensibi, darboğaz teorisi
- **Test otomasyonu:** piramit (unit çok / E2E az); bu reponun gerçek katmanları — `npm test` (içerik unit testi), `npm run build` (integration), E2E (tarayıcı)
- **GitHub Actions:** workflow→job→step, tetikleyiciler, `needs` zinciri, matrix; `npm ci` disiplini
- **Secrets & Environments:** maskelenmiş secret’lar, fork PR’larına erişim yok, production environment onay kapısı
- **Cache & Artifact:** cache hıza, artifact taşımaya yarar; “build → artifact → deploy” deseni
- **Deploy stratejileri:** staging/prod ayrımı, smoke test (`curl` doğrulaması), rollback’i deploy’dan önce planlama
