## Özet haritası

- **DevOps nedir:** bir araç değil, “sen yaz, sen çalıştır” diyen bir çalışma biçimi; hedef, Dev–Ops duvarını yıkmak (DORA metrikleri bunu ölçer)
- **Kültür ve tarihçe:** Waterfall’ın gecikmiş geri bildirimi → Agile’ın deployment darboğazı → 2009 DevOpsDays; CALMS çerçevesi ve blameless postmortem zihniyeti
- **Kariyer yolları:** DevOps (teslim hattı), SRE (ölçülebilir güvenilirlik), Platform Engineering (self-service ürün) — ortak zemin: Linux + ağ + Git
- **Bu site bir DevOps projesi:** dersler Content Collections + Zod şemasıyla doğrulanır, CI ile derlenir, Pages’te yayınlanır — dogfooding
- **Araç kurulum rehberi:** Git, Node, GitHub CLI ve (Windows’ta) WSL2 — her kurulum `--version` ile doğrulanır
