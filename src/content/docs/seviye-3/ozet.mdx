## Özet haritası

- **Docker:** container = host kernel paylaşan izolasyon; katman cache’i (manifest önce kopyalanır), multi-stage ile 77MB imaj, registry + sha tag disiplini, compose ile çoklu servis (servis adı = DNS)
- **Kubernetes:** desired state + kontrol döngüsü (self-healing); Pod/Deployment/Service üçlüsü; rolling update ve `rollout undo`; Ingress (TLS), ConfigMap/Secret, Helm paketleme
- **Bulut (vendor-neutral):** compute/storage/network/IAM soyutlamaları, shared responsibility, serverless vs CDN vs monolit kararı yük profiline göre
- **IaC:** Terraform (init→plan→apply, state + lock), Ansible (idempotent playbook’lar), kısa ömürlü ortamlar ve etiketleme ile maliyet kontrolü
