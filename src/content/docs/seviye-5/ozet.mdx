## Özet haritası

- **GitOps:** Git = istenen hâl; ArgoCD/Flux pull modeliyle sürekli eşitler (drift onarımı, `git revert` = küme rollback) — repoda kind kümesine gerçek ArgoCD lab’ı var
- **Deployment desenleri:** deploy ≠ release; blue-green (anlık switch), canary (ölçülü dilim), feature flag (kill switch); DB şemalarında expand–migrate–contract
- **Platform engineering:** golden path, adoption metriği, Backstage — platform bir üründür
- **Sektörel pratikler:** finans/sağlık/kamuda compliance as code; e-ticaret/oyun/medyada degradasyon merdiveni ve game day; AI’nin dört katmanı ve sağlam kullanım kuralları
- **Gerçek olay arşivi:** Knight Capital, AWS S3, GitLab, Cloudflare, Equifax, Facebook — her biri “hangi seviye bunu önlerdi?” sorusuyla okunur
- **Capstone:** CI → imaj → GitOps → küme → SLO’lu monitoring; dört dayanıklılık provasıyla kanıtlanmış production
