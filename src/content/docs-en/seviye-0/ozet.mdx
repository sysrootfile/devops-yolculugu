## Summary map

- **What DevOps is:** not a tool but “you write it, you run it”; the goal is tearing down the Dev–Ops wall (DORA metrics measure it)
- **Culture and history:** Waterfall's delayed feedback → Agile's deployment bottleneck → 2009 DevOpsDays; the CALMS framework and the blameless mindset
- **Career paths:** DevOps (delivery), SRE (measurable reliability), Platform Engineering (self-service product) — common ground: Linux + networking + Git
- **This site is a DevOps project:** lessons are validated with a Zod schema, built by CI, published on Pages — dogfooding
- **Tool setup guide:** Git, Node, GitHub CLI and (on Windows) WSL2 — every install verified with `--version`
